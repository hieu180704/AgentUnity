# 1. Quy định ghi nhận Handoff
Thư mục này chứa nhật ký tóm tắt giao việc giữa các phiên làm việc (Session Handoffs).
Mỗi khi kết thúc một task lớn hoặc chuẩn bị đổi phiên chat mới, AI sẽ tạo 1 file dạng `YYYY-MM-DD_task_name.txt` lưu tại đây.
Khi mở phiên chat mới, chỉ cần nhắc AI đọc file handoff mới nhất để tiếp tục công việc mà không bị ngắt quãng.
