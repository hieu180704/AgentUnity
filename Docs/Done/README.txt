# 1. Quy định về thư mục Done
Thư mục này lưu trữ các file fragment ghi nhận các việc đã hoàn thành gọn dạng `<date>__<slug>.txt` do skill `/newsession` sinh ra.
Mỗi file fragment ghi rõ SUMMARY mang trạng thái VERIFY (play-test PASS / CHƯA verify / compile-green only) và commit SHA.
